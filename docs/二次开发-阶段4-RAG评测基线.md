# 阶段 4：RAG 检索质量评测基线报告

> 生成时间：2026-10-11 ｜ 评测集：`evaluation/rag-eval-set.json` v1（56 条）
> 评测环境：本机真实全链路（MySQL + pgvector + MinIO + ES + DashScope）

## 1. 评测方法

### 1.1 评测集构成（56 条）

| 类别 | 数量 | 说明 | 判分标准 |
|---|---|---|---|
| fact 事实单点 | 30 | 版本号、端口、参数、规则等可验证事实 | 检索命中 + 答案关键词全命中 |
| term 术语解释 | 8 | RAG/RRF/pgvector/HNSW 等术语 | 同上 |
| cross 跨段落 | 8 | 需要跨季度、跨文档关联的事实 | 同上 |
| unanswerable 无答案 | 4 | 知识库中不存在的问题 | 正确拒答（answered=false） |
| permission 权限 | 6 | 机密群组文档相关问题（以普通评测账号提问） | 不泄漏 + 正确拒答 |

评测语料：10 篇受控事实文档（`evaluation/eval_docs/`，8 篇公开 + 2 篇机密），
公开文档上传至评测群，机密文档上传至**另一账号**的机密群，用于权限泄漏检测。

### 1.2 检索与生成配置基线（本次记录，后续对比以此为准）

| 配置项 | 基线值 |
|---|---|
| 切片策略 | 结构感知（Markdown 标题/段落边界） |
| 切片长度 | 目标 240 token / 最大 320 token / 重叠 32 token |
| 向量检索 Top-K | 10（pgvector HNSW，余弦距离，vector(512)） |
| 关键词检索 Top-K | 10（ES 8.14 + IK ik_max_word） |
| 证据切片上限 | 6 |
| 分数阈值 | 0.30 |
| Embedding | DashScope text-embedding-v3（512 维） |
| 生成模型 | qwen-plus |

### 1.3 指标定义

- **检索命中率（Retrieval Hit Rate）**：期望文档出现在 `evidenceOverview.groups` 中的比例
- **MRR**：期望文档在证据分组（服务端按相关性排序）中排名倒数的均值
- **答案关键词正确率**：`expect_keywords` 全部出现在答案中的比例（自动代理指标，受措辞影响存在低估）
- **拒答正确率**：无答案问题被正确拒答的比例
- **权限泄漏率**：机密文档出现在证据/引用中的比例（期望 0）

## 3. 明细分析

### 3.1 检索排序（MRR 未达 1 的 5 条，均命中只是排名靠后）

| 题目 | 期望排名 |
|---|---|
| Argus 平台的默认服务端口是多少？ | 2 |
| 数据库备份是什么时候执行的？保留多久？ | 2 |
| Argus 中的 ETL 流水线包含哪些阶段？ | 3 |
| 秒传是什么意思？它的判断依据是什么？ | 2 |
| Argus 的向量库和关键词检索分别用什么组件实现？ | 2 |

共同特征：问题同时涉及多篇文档（跨文档场景）或查询词与高相似度段落竞争，
期望文档进了证据但排序第二/第三。由于证据上限 6 且命中 100%，**对最终答案质量影响有限**。

### 3.2 答案关键词未命中（7/46 = 15.2%）

抽查确认：未命中条目均为**回答正确但措辞与关键词模板不完全一致**（如 Q7 回答了
"groups 是 MySQL 8.0 保留字"并给出改名 argus_groups，但未逐字包含预设的全部关键词），
未发现真实的事实性错误。该指标作为自动代理指标存在**天然低估**，精确的回答正确率
需要人工复核或 LLM-as-judge（列入后续优化项）。

### 3.3 可靠性与安全亮点

- 无答案场景 100% 拒答，未出现幻觉作答；
- **权限隔离 0 泄漏**：跨群机密文档（薪酬/未发布产品）在证据、引用、答案中均未出现；
- 延迟 P95 3.72s，满足方案 Q3「P95 < 3s」目标线附近（考虑本机环境，未做并发压测）。

## 5. 结论与后续优化方向

1. **检索召回已达标**（100% 命中），排序是下一个提升点：可调 RRF 权重或引入重排器，
   目标 MRR 0.942 → 0.97+；
2. 答案正确率评估需引入 LLM-as-judge 替代关键词匹配，消除措辞性低估；
3. 权限隔离表现完美，可作为回归基线纳入 CI；
4. 本报告为**单机串行**基线，并发指标（吞吐/错误率）见阶段 6 压测报告。
