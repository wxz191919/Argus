# Argus 平台概述

Argus 是一个企业级智能知识库平台，核心能力是将团队分散的文档转化为可智能问答的知识资产。

## 基本信息

Argus 平台当前版本号为 2.4.0，采用 B/S 架构，后端基于 Java 21 与 Spring Boot 3.5.0 开发，前端基于 Vue3 与 TypeScript。平台默认服务端口为 10001，API 文档通过 Knife4j 提供，访问路径为 /doc.html。

## 核心模块

平台由五大核心模块组成：文档摄入模块（负责文档上传与 ETL 处理）、检索引擎模块（负责混合检索与重排）、问答模块（负责答案生成与引用溯源）、权限模块（负责群组与角色管理）、运维模块（负责任务监控与统计）。

## 支持的文档格式

Argus 支持上传的文档格式包括：TXT 纯文本、Markdown、PDF、DOCX 四种。单个文档大小限制为 50MB，单个群组的文档数量上限为 1000 个。

## 部署形态

Argus 支持两种部署形态：单机便携部署（适合小于 50 人的团队）和容器化集群部署（适合 50 人以上的团队）。容器化部署依赖 Docker Compose 编排。
