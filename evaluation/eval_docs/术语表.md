# 术语表

本文档定义 Argus 平台相关的核心术语。

## RAG

RAG 全称 Retrieval-Augmented Generation，中文为检索增强生成。指在大模型回答问题前，先从知识库检索相关片段，将其作为证据提供给大模型，从而提升答案准确性并支持引用溯源。

## RRF

RRF 全称 Reciprocal Rank Fusion，中文为倒数排名融合。是一种将多路检索结果（如向量检索和关键词检索）合并为统一排序的算法，每条结果的融合分数等于各路排名倒数的加权和。

## pgvector

pgvector 是 PostgreSQL 数据库的向量检索扩展，支持存储 embedding 向量并执行相似度检索。Argus 使用 pgvector 的 HNSW 索引加速余弦相似度查询。

## HNSW

HNSW 全称 Hierarchical Navigable Small World，中文为分层可导航小世界图。是一种高性能的近似最近邻检索索引结构，检索复杂度为对数级，适合百万级以上向量规模。

## ETL

ETL 全称 Extract-Transform-Load，即提取、转换、加载。在 Argus 中指文档从原始文件解析为文本、切分为切片、生成向量并写入检索索引的完整流水线。

## IK 分词器

IK 分词器是 Elasticsearch 生态中最常用的中文分词插件，支持 ik_max_word（最细粒度切分）和 ik_smart（智能粗粒度切分）两种模式。Argus 索引默认使用 ik_max_word。
