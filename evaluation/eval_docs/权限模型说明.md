# 权限模型说明

本文档说明 Argus 平台的权限与授权模型。

## 角色体系

平台共有三类系统角色：SYSTEM_ADMIN（系统管理员）、GROUP_OWNER（群组管理员）、GROUP_MEMBER（普通成员）。系统管理员可以管理全部用户，群组管理员可以管理本群组的文档和成员，普通成员只能阅读群组内的文档并发起问答。

## 群组隔离

所有知识库资源以群组为隔离边界。用户只能访问自己加入的群组，跨群组访问文档、检索、问答、下载都会被服务端拒绝并返回 403。权限校验在服务端统一执行，不依赖前端隐藏按钮。

## 成员管理

邀请成员加入群组会产生一条 PENDING 状态的邀请记录，被邀请人接受后成为 GROUP_MEMBER。用户主动申请加群会产生加群申请记录，由群组管理员审批。

## 审计要求

删除文档、修改成员角色、审批加群申请三类操作必须记录审计日志，日志包含操作人、操作对象、操作时间和来源 IP。
