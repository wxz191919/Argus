# 检索质量规范

本文档定义 Argus RAG 检索链路的质量规范与参数基线。

## 切片参数

文档切片采用结构感知策略，按 Markdown 标题和段落边界切分。基线参数为：目标切片长度 240 token，最大切片长度 320 token，相邻切片重叠 32 token。

## 混合检索

检索链路采用混合检索策略：向量检索基于 pgvector 的 HNSW 索引，使用余弦距离度量；关键词检索基于 Elasticsearch 的 IK 中文分词器。两路结果通过 RRF（倒数排名融合）合并排序。

## 检索参数基线

检索参数基线如下：向量检索 Top-K 为 10，关键词检索 Top-K 为 10，最终送入大模型的证据切片数量上限为 6。相关性分数低于 0.30 的切片会被过滤。

## 向量模型

向量 embedding 采用 DashScope 的 text-embedding-v3 模型，输出维度为 512。答案生成采用 qwen-plus 模型。

## 引用溯源

每个回答必须返回引用来源，包含文档 ID、切片 ID、切片序号、文件名和相关性分数。证据不足时系统应拒答并返回 INSUFFICIENT_EVIDENCE 原因码。
