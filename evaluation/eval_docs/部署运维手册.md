# 部署运维手册

本文档说明 Argus 平台的部署要求与日常运维操作。

## 基础设施依赖

Argus 平台运行依赖五个基础设施组件：MySQL 8.0（业务数据）、PostgreSQL 16 加 pgvector 扩展（向量数据）、MinIO（文档对象存储）、Elasticsearch 8（关键词检索索引）、DashScope API（向量与问答模型服务）。

## 端口分配

默认端口分配如下：后端服务 10001，MySQL 3306，PostgreSQL 5432，MinIO API 9000，MinIO 控制台 9001，Elasticsearch 9200。

## 健康检查

后端健康检查端点为 /actuator/health，返回 UP 表示服务正常。MinIO 的健康检查端点为 /minio/health/live。Elasticsearch 集群健康状态达到 yellow 即可对外服务。

## 日常运维

每天凌晨 2 点系统自动执行 MinIO 对象的生命周期检查，清理超过 90 天的临时上传分片。每周日 3 点执行数据库备份，备份保留 30 天。

## 故障排查

后端启动失败的常见原因：端口被占用（检查 10001）、数据库连接失败（检查 MySQL 账号密码）、ES 不可达（检查 9200 端口）。所有故障日志集中在 logs/argus-backend.log。
